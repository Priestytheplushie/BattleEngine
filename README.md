# BattleEngine
A basic terminal RPG battle system

## Prerequisites
* [.NET SDK](https://dotnet.microsoft.com/download)

## How to play 

```bash
dotnet run

```

You can modify the `Enemy` class to change the encounter or modify the `Player` class to change your stats

## How to Play

* Follow the on-screen prompts.
* Enter the number corresponding to your choice and press **Enter**.
* Defeat the beast to win!
